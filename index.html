사진 자동 인식 (Anthropic API)

이 앱은 서버가 없는 단일 HTML 파일이라, 사진 분석은 브라우저에서 Anthropic API를 직접 호출합니다. API 키는 이 컴퓨터의 크롬 저장소에만 평문으로 저장되며 다른 곳으로 전송되지 않습니다(사진과 함께 Anthropic 서버로만 전송). 키는 console.anthropic.com 에서 발급받을 수 있고, 이미지 1장 분석 비용은 통상 수 원 수준입니다. 공용 PC에서는 사용하지 마세요.

내 신체 정보 (목표 자동 계산)

입력하면 Mifflin-St Jeor 공식으로 기초대사량(BMR)과 일일 소비 열량(TDEE)을 계산해 목표값을 제안합니다. 공식 자체에도 개인차가 ±10% 정도 있으므로, 2~3주 기록 후 실제 체중 변화를 보고 조정하는 것이 가장 정확합니다.

일일 목표

기본값은 1일 2,000kcal 기준의 일반 성인 참고치입니다(한국인 영양소 섭취기준의 에너지적정비율 — 탄수화물 55~65%, 단백질 7~20%, 지방 15~30% 범위 내). 나트륨 2,000mg은 WHO 권고 상한이며, 한국인 영양소 섭취기준의 만성질환위험감소섭취량은 2,300mg입니다. 나트륨은 채우는 목표가 아니라 넘지 않아야 할 상한으로 보세요. 성별·연령·활동량·건강상태에 따라 실제 필요량은 달라지므로 필요시 조정하세요.

데이터 백업 / 이전

식사 기록·체중·신체 정보 모두 이 브라우저 안에만 저장됩니다. 다른 기기·다른 주소(파일로 열기 ↔ 웹 주소)로 옮기려면 아래로 내보낸 뒤 그쪽에서 가져오세요. 브라우저의 "쿠키 및 사이트 데이터 삭제"를 하면 기록이 지워지므로 가끔 백업해두시길 권합니다. API 키는 백업 파일에 포함되지 않습니다(유출 방지) — 새 기기에서는 키만 다시 입력하시면 됩니다.
