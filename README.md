# 오늘의 영양 기록

하루 섭취 칼로리와 주 영양소(탄수화물 · 단백질 · 지방 · 식이섬유 · 나트륨 · 수분)를 기록하는 개인용 웹앱입니다.
의존성 없는 단일 HTML 파일이며, 별도의 서버나 빌드 과정이 없습니다.

## 기능

- **문장 입력** — "오곡찰밥 2/3공기, 우거지국 2/3인분, 진미채 3젓가락"처럼 적으면 항목별로 분해해 계산합니다. 합계는 앱이 직접 더하므로 산술 오류가 없습니다
- **사진 인식** — 영양성분표나 음식 사진을 올리면 영양정보를 자동으로 채웁니다 (한 번에 최대 10장)
- **AI 음식 검색** — 음식 이름을 입력하면 일반적인 1인분 영양성분을 추정합니다
- **직접 입력** — 수동 입력, 분석 결과 텍스트 붙여넣기 자동 파싱
- **즐겨찾기** — 자주 먹는 음식을 저장해 한 번에 추가
- **나트륨 추적** — 한 끼가 하루 상한의 몇 %인지 표시 (기본 상한 2,000mg)
- **목표 자동 계산** — 키·나이·성별·활동량으로 기초대사량(Mifflin-St Jeor)과 일일 소비 열량을 계산해 목표값을 제안합니다
- **체중 기록** — 일별 체중과 7일 이동평균 추이. 기록한 섭취량과 실제 체중 변화를 대조해 실제 소비 열량을 역산합니다
- **추세 그래프** — 7 / 14 / 30일 일별 칼로리와 3대 영양소 추이, 기간 평균 대비 목표
- **백업** — 기록을 JSON으로 내보내고 다른 기기에서 가져오기

## 데이터와 개인정보

이 사이트는 **서버에 아무것도 저장하지 않습니다.** 기록과 설정은 접속한 사람의 브라우저
로컬 저장소(localStorage)에만 저장됩니다. 따라서 주소를 아는 사람이 접속해도 빈 앱 화면만
보이며, 다른 사람의 기록은 볼 수 없습니다.

사진 인식과 AI 검색 기능은 Anthropic API를 브라우저에서 직접 호출합니다. 이를 위한 API 키는
사용자 본인의 브라우저에만 저장되며, 이 저장소나 서버에는 포함되어 있지 않습니다.
백업 파일에도 API 키는 포함되지 않습니다.

브라우저의 "쿠키 및 사이트 데이터 삭제"를 실행하면 기록이 함께 지워집니다. 설정 화면에서
주기적으로 백업하시기를 권합니다.

## 사용법

1. 배포된 주소에 접속합니다.
2. 사진 인식 / AI 검색을 쓰려면 ⚙️ 설정에서 Anthropic API 키를 등록합니다.
   (키 없이도 직접 입력, 즐겨찾기, 추세 그래프는 모두 동작합니다.)
3. 휴대폰에서는 크롬 메뉴 → "홈 화면에 추가"로 앱처럼 사용할 수 있습니다.

## 정확도에 대하여

- 영양성분표 사진에서 읽은 값에는 `라벨` 배지가 붙습니다 — 표기값 그대로입니다.
- 음식 사진 추정과 AI 검색 결과에는 `추정` 배지가 붙습니다 — 조리법과 양에 따라 오차가 큽니다.
- 수분과 나트륨은 라벨에 없으면 추정값입니다. 한식은 간에 따라 나트륨 편차가 큽니다.
- 나트륨 기본 상한 2,000mg은 WHO 권고치이며, 한국인 영양소 섭취기준의 만성질환위험감소섭취량은 2,300mg입니다.
- 탄수화물·단백질·지방으로 계산한 열량(Atwater 계수 4/4/9 kcal/g)이 표기 칼로리와 25% 이상
  차이 나면 검산 경고를 표시합니다.
- 기초대사량 추정식 자체에 ±10% 정도의 개인차가 있습니다. 2~3주 기록 후 실제 체중 변화로
  보정하는 것이 가장 정확하며, '체중' 탭이 그 역산을 해줍니다.
- 감량 목표가 기초대사량 아래로 내려가면 자동으로 기초대사량까지만 낮추고 경고를 표시합니다.

이 앱은 건강 관리 참고 도구이며 의학적 조언을 대신하지 않습니다. 기저질환이 있거나
목표 섭취량이 낮게 산출되는 경우 의사·영양사와 상의하시기 바랍니다.

## 수정 방법

`index.html` 하나만 편집하면 됩니다. GitHub에서 파일을 열어 연필 아이콘으로 수정하고
커밋하면 1~2분 내 사이트에 반영됩니다.
